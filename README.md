# FlowRight Plumbing

A high-converting, professional landing page for **FlowRight Plumbing**, built with Next.js 14 App Router, TypeScript, Tailwind CSS 3.4, Framer Motion, and Lucide React icons.

## Overview

This project is a placeholder demo landing page designed with strict adherence to modern UI/UX design tokens:
- **Primary Deep Navy:** `#0A1128`
- **Surface:** `#121E3B`
- **Accent Electric Cyan:** `#00E5FF`
- **Copper:** `#D48356`
- **Muted Text:** `#94A3B8`
- **Borders:** `#1E293B`
- **Typography:** Plus Jakarta Sans (Display) & Inter (Body)

## Features

- 24/7 Emergency Plumbing & Scheduled Services (Residential & Commercial)
- Fully responsive components with fluid layouts and micro-interactions
- Built-in Schema.org LocalBusiness JSON-LD structured data
- Interactive sections including trust badges, service grids, emergency alert bands, process breakdown, project showcases, testimonials, service areas, transparent pricing, and FAQs with a conversion-focused CTA.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS 3.4
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Getting Started

Follow these steps to run the project locally:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser to view the landing page.

4. Build for production:
   ```bash
   npm run build
   ```

5. Start the production server:
   ```bash
   npm start
   ```
