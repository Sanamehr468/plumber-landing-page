# FlowFix Plumbing — Landing Page

A professional plumbing landing page built with Next.js and Framer Motion, for testing.

Inspired by high-converting professional plumber websites: emergency and scheduled
bookings are split into separate paths, the phone number and 24/7 cover are above
the fold, trust signals (licensed & insured, reviews, on-time guarantee) are visible
early, services are grouped by the customer's problem, service areas are named, and
pricing guidance is shown upfront with no hidden charges.

This is a fictional test business. The phone number and email shown on the page
are test details, not a real business.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
